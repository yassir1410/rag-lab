# Sample Documents for Testing

This directory contains representative, non-confidential sample files for testing document ingestion and parsing in the RAG Engineering Lab.

## Files
- `rag_overview.txt`: Standard UTF-8 plain text with multiple paragraphs.
- `architecture_guide.md`: Markdown document with headers, code fences, and tables.
- Additional test files can be uploaded directly via the web dashboard or generated programmatically during automated tests.
